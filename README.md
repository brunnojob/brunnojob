# Brunno Dev

Desenvolvimento de sistemas, automação industrial e aplicações com persistência de dados.

[Arquivo de operações](https://vercel-home-telemetry-api.vercel.app/laboratory.html) · [Site](https://brunnodev.store)

## Projetos

| Repositório | Implementação |
|---|---|
| [Offshore Field Console](https://github.com/brunnojob/android-offshore-field-console) | Aplicativo Android para inspeções com checklist obrigatório, referência de evidência, banco Room e sincronização autenticada de eventos. |
| [Air Quality Monitor](https://github.com/brunnojob/arduino-air-quality-monitor) | Monitor ADC com janela móvel, variância, aquecimento, confirmação de limiar, histerese e identificação de falha de sensor. |
| [ESP32 Telemetry](https://github.com/brunnojob/arduino-cloud-telemetry) | Aquisição calibrada, qualidade de sinal, sequência por sensor, buffer limitado e confirmação de entrega serial. |
| [Smart Irrigation](https://github.com/brunnojob/arduino-smart-irrigation) | Controle de irrigação com filtro, histerese, intervalo mínimo, tempo máximo de bomba, sensor de reservatório e bloqueio por falha. |
| [Bank Ledger](https://github.com/brunnojob/bank-crypto-ledger) | Motor contábil e diário persistente de partidas balanceadas por moeda, com idempotência, bloqueio de arquivo, precisão inteira e verificação de encadeamento. |
| [NOVA Administration](https://github.com/brunnojob/bet-admin-dashboard) | Painel administrativo com sessões, CRUD de sites e domínios, registros financeiros, integração Mercado Pago e relatórios por dia e estado. |
| [File Integrity Audit](https://github.com/brunnojob/c-file-integrity-audit) | Inventário recursivo de arquivos com SHA-256, comparação de tamanho e identificação de inclusões, alterações e remoções. |
| [Household Budget](https://github.com/brunnojob/c-household-budget) | Consolidação de receitas e despesas por mês e categoria, com valores inteiros em centavos e validação estrita de datas e registros. |
| [NOVA Play](https://github.com/brunnojob/casino-simulator-brunnodev) | Aplicativo de entretenimento com regras distintas para roletas, dados e slots, amostragem aleatória sem viés modular e histórico exportável. |
| [Safe Task Queue](https://github.com/brunnojob/cpp-safe-task-queue) | Executor concorrente com capacidade limitada, prioridades, prazo de execução, futures e encerramento com drenagem ou cancelamento. |
| [Water Leak Monitor](https://github.com/brunnojob/cpp-water-leak-alarm) | Análise de leituras com filtro, histerese, confirmação temporal, falha de sensor e alarme retido até reconhecimento. |
| [Pantry API](https://github.com/brunnojob/csharp-pantry-api) | API de estoque doméstico com validade, localização, movimentos auditados, idempotência e controle otimista de revisão. |
| [Electrical Circuit Engine](https://github.com/brunnojob/eletrical-comands-and-teory) | Interpretador de circuitos com contatos NO/NC, lógica AND/OR, temporização TON, retenção por estado anterior e exclusão de bobinas simultâneas. |
| [FaceClock Review API](https://github.com/brunnojob/faceclock-yolo) | Detecção de rosto, embeddings, propostas de identificação e revisão humana antes do registro de presença, com templates cifrados e trilha autenticada. |
| [Repository Insights](https://github.com/brunnojob/fuckup) | Análise de repositórios públicos do GitHub com linguagens, contribuidores, commits, duração de issues e critérios observáveis de estrutura. |
| [Industrial IoT Sentinel](https://github.com/brunnojob/industrial-iot-sentinel) | Gêmeo operacional de ocupação de embarcação, capacidade por zona, função de pessoas e movimentos idempotentes, recuperados de um diário SQLite. |
| [Fuel Log](https://github.com/brunnojob/java-fuel-efficiency) | Registro persistente de abastecimentos, custos decimais e consumo entre tanques completos, incluindo abastecimentos parciais. |
| [Medication Schedule](https://github.com/brunnojob/java-medication-schedule) | Agenda de horários informados pelo usuário, com fuso horário, tratamento de mudanças de horário e histórico de registros. |
| [Repair Log](https://github.com/brunnojob/java-neighborhood-repair-log) | Gestão de solicitações com prioridades, responsáveis, transições de estado, revisão esperada e histórico de eventos persistente. |
| [Industrial Automation](https://github.com/brunnojob/nodered-industrial-automation) | Fluxo MQTT e Node-RED com unidades de engenharia, controle de sequência, qualidade, histerese de alarme e fila persistente de envio. |
| [Offshore SCADA](https://github.com/brunnojob/offshore-scada-simulator) | Servidor local com WebSocket, Modbus TCP, normalização de sinais, alarmes com confirmação e histórico agregado por intervalo. |
| [NOVA Operations](https://github.com/brunnojob/painel-admin-aposta) | Painel autenticado de ordens de serviço, prioridade, transição de estado, telemetria recente, filtros e exportação. |
| [Git Collaboration Audit](https://github.com/brunnojob/pair-extraordinaire-badge) | Auditoria de histórico Git, autores, trailers de coautoria, mudanças de arquivos e colaboração associada a alterações substantivas. |
| [Pressure Control](https://github.com/brunnojob/pid-pressure-control) | Controlador PID com intertravamentos e identificação de modelo de primeira ordem a partir de medições do processo. |

| [SCADA Code Studio](https://github.com/brunnojob/scada-code-studio) | Interface interativa de comandos elétricos, diagramas ladder e estados de motor, com controles acessíveis e exportação do histórico de ações. |
| [POS Core](https://github.com/brunnojob/secure-payment-pos-core) | Aplicativo Android para catálogo, estoque, registro de vendas recebidas em dinheiro, eventos assinados no Keystore e fila de sincronização. |
| [Trazor Ledger](https://github.com/brunnojob/trazorbypasssafe7) | Contas contábeis pessoais, entradas e despesas, histórico persistente, exportação e lançamentos transacionais com revisão esperada. |
| [Auth Gateway](https://github.com/brunnojob/zero-trust-auth-gateway) | Gateway com tokens de curta duração, escopos, proteção contra repetição, limites e auditoria; autenticação Supabase para consulta de relatórios privados. |
