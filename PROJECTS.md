## Operational implementations

| Repository | Implementation |
|---|---|
| [Offshore Field Console](https://github.com/brunnojob/android-offshore-field-console) | Android inspections with mandatory checklists, evidence references, Room persistence and authenticated event synchronization. |
| [Air Quality Monitor](https://github.com/brunnojob/arduino-air-quality-monitor) | ADC monitoring with rolling windows, variance, warm-up, threshold confirmation, hysteresis and sensor fault detection. |
| [ESP32 Telemetry](https://github.com/brunnojob/arduino-cloud-telemetry) | Calibrated acquisition, signal quality, per-sensor sequences, bounded buffering and serial delivery acknowledgements. |
| [Smart Irrigation](https://github.com/brunnojob/arduino-smart-irrigation) | Irrigation control with filtering, hysteresis, minimum intervals, pump timeouts, reservoir sensing and fault lockout. |
| [Bank Ledger](https://github.com/brunnojob/bank-crypto-ledger) | Persistent ledger with balanced entries per currency, idempotency, file locking, integer precision and chain verification. |
| [NOVA Administration](https://github.com/brunnojob/bet-admin-dashboard) | Administration dashboard with sessions, site and domain CRUD, financial records, Mercado Pago integration and reports by day and status. |
| [File Integrity Audit](https://github.com/brunnojob/c-file-integrity-audit) | Recursive SHA-256 file inventory with size comparisons and detection of additions, changes and deletions. |
| [Household Budget](https://github.com/brunnojob/c-household-budget) | Monthly income and expense summaries by category, integer cents and strict date and record validation. |
| [NOVA Play](https://github.com/brunnojob/casino-simulator-brunnodev) | Entertainment app with distinct roulette, dice and slot rules, sampling without modulo bias and exportable history. |
| [Safe Task Queue](https://github.com/brunnojob/cpp-safe-task-queue) | Bounded concurrent executor with priorities, deadlines, futures and shutdown by draining or cancellation. |
| [Water Leak Monitor](https://github.com/brunnojob/cpp-water-leak-alarm) | Reading analysis with filtering, hysteresis, temporal confirmation, sensor fault detection and latched alarms requiring acknowledgement. |
| [Pantry API](https://github.com/brunnojob/csharp-pantry-api) | Household inventory API with expiry dates, locations, audited movements, idempotency and optimistic revision control. |
| [Electrical Circuit Engine](https://github.com/brunnojob/eletrical-comands-and-teory) | Circuit interpreter with NO/NC contacts, AND/OR logic, TON timers, previous-state retention and mutually exclusive coils. |
| [FaceClock Review API](https://github.com/brunnojob/faceclock-yolo) | Face detection, embeddings, identity proposals and human review before attendance registration, with encrypted templates and an authenticated audit trail. |
| [Repository Insights](https://github.com/brunnojob/fuckup) | Public GitHub repository analysis covering languages, contributors, commits, issue duration and observable structure criteria. |
| [Industrial IoT Sentinel](https://github.com/brunnojob/industrial-iot-sentinel) | Vessel occupancy model with zone capacities, personnel roles and idempotent movements recovered from a SQLite journal. |
| [Fuel Log](https://github.com/brunnojob/java-fuel-efficiency) | Persistent fuel records with decimal costs and consumption between full tanks, including partial fills. |
| [Medication Schedule](https://github.com/brunnojob/java-medication-schedule) | User-defined schedules with time zones, clock-change handling and event history. |
| [Repair Log](https://github.com/brunnojob/java-neighborhood-repair-log) | Request management with priorities, assignees, state transitions, expected revisions and persistent event history. |
| [Industrial Automation](https://github.com/brunnojob/nodered-industrial-automation) | MQTT / Node-RED flow with engineering units, sequence checks, signal quality, alarm hysteresis and a persistent outbound queue. |
| [Offshore SCADA](https://github.com/brunnojob/offshore-scada-simulator) | Local server with WebSocket, Modbus TCP, signal normalization, acknowledged alarms and history aggregated by interval. |
| [NOVA Operations](https://github.com/brunnojob/painel-admin-aposta) | Authenticated work-order dashboard with priorities, state transitions, recent telemetry, filters and export. |
| [Git Collaboration Audit](https://github.com/brunnojob/pair-extraordinaire-badge) | Git history audit covering authors, co-author trailers, file changes and collaboration tied to substantive changes. |
| [Pressure Control](https://github.com/brunnojob/pid-pressure-control) | PID control with interlocks and first-order model identification from process measurements. |
| [PLC Modbus Controller](https://github.com/brunnojob/plc-modbus-safety-controller) | Motor state machine with interlocks, Structured Text reference and Modbus TCP frame processing. |
| [SCADA Code Studio](https://github.com/brunnojob/scada-code-studio) | Interactive electrical commands, ladder diagrams and motor states, with accessible controls and action-history export. |
| [POS Core](https://github.com/brunnojob/secure-payment-pos-core) | Android catalog, inventory, cash-sale records, Keystore-signed events and a synchronization queue. |
| [Trazor Ledger](https://github.com/brunnojob/trazorbypasssafe7) | Personal accounts, income and expenses, persistent history, export and transactional entries with expected revisions. |
| [Auth Gateway](https://github.com/brunnojob/zero-trust-auth-gateway) | Gateway with short-lived tokens, scopes, replay protection, rate limits and auditing; Supabase authentication for private reports. |
